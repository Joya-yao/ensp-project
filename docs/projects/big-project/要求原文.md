# 大项目：ensp实验1 双核心园区网

拓扑文件：`ensp实验1.topo`（11 台设备：AR1 出口、LSW1/LSW2 双核心、LSW3~LSW6 接入、PC1~PC4）

拓扑现状：AR1（出口路由器）、LSW1（S5700）、LSW2（S5700）、LSW3/LSW4/LSW5/LSW6（S3700 接入）、PC1~PC4。

要求原文：

1. LSW1 是主核心，LSW2 是备用。
2. 跑 OSPF、MSTP、VRRP，用来做负载均衡和防环。
3. 要有链路聚合。
4. 接入交换机分别是销售部、后勤部、财务部、研发部。
5. 其他人不能访问财务部，但是财务部可以访问其他部门。
